# EPIC12 · Plugins Claude

Plugin Claude pour dirigeants de startups et scale-ups : les questions de leader, cadrées par la méthode EPIC12. Les skills de la série vidéo « Question de leader ».

## Installer
Dans claude.ai : Personnaliser > Plugins > Ajouter > Ajouter un marketplace, puis colle l'URL de ce dépôt.

## Commandes
- `/epic12` : la porte d'entrée, pour poser son sujet du moment.
- `/comex-au-niveau` : mon Comex est-il une bonne équipe ?
- `/c-level-au-niveau` : mon C-level est-il au niveau ?
